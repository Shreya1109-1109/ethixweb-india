# Ethixweb India - Modern Landing Page & Admin Dashboard

A high-performance business website and lead management platform built with modern web technologies.

## 🚀 Live Demo & Repository
- **Live URL:** [https://ethixweb-india-iota.vercel.app](https://ethixweb-india-iota.vercel.app)
- **GitHub Repository:** [https://github.com/Shreya1109-1109/ethixweb-india](https://github.com/Shreya1109-1109/ethixweb-india)

## 🛠️ Tech Stack
- **Frontend & Routing:** Next.js (App Router, React)
- **Styling:** Tailwind CSS (Custom Glassmorphism utilities & 3D ambient glows)
- **Backend & Database:** Supabase (PostgreSQL for real-time lead storage)
- **Deployment:** Vercel

## ✨ Key Features
- **Modern UI/UX:** Glassmorphism cards with smooth hover effects, frosted glass modals, and responsive layouts.
- **3D Ambient Background:** Futuristic glowing gradients for enhanced visual appeal.
- **Real-Time Contact Form:** Instant enquiry capture with success popups and toast notifications.
- **Protected Admin Dashboard:** Secure login (`/admin`) featuring live search, record deletion, and CSV export functionality.

## 💡 Design Rationale
- Designed to deliver a lightning-fast user experience with zero layout shifts. 
- Uses translucent layers (`backdrop-blur-xl`) and subtle borders to achieve a high-end, futuristic SaaS aesthetic tailored for modern businesses.
